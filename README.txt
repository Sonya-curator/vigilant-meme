
Node Map Template
=================

This package contains two versions of a floating node map:

1. **2D Version** (HTML/CSS/JS)
2. **3D Version** (Three.js)

Each node contains an image, text, and hyperlink. Nodes gently float and connect with lines.

Instructions:
------------
- Open `2d/index.html` in a browser for the 2D version.
- Open `3d/index.html` in a browser for the 3D version.
- Replace images in the `images/` folder with your own JPEG or PNG files.
- Edit the HTML files to update node text, links, and image paths.

Hosting:
--------
You can host this on GitHub Pages or any static web server.

Customization:
--------------
- Add more nodes by duplicating the HTML blocks or JavaScript objects.
- Adjust animation speed and style in the script sections.
- Use external data sources (JSON, CMS) for dynamic content.
